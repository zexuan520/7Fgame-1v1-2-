# 字体

`fusion-pixel.ttf`：Fusion Pixel（缝合像素字体），作者 TakWolf，使用 SIL Open Font License 1.1 授权，可免费用于商业游戏。
项目主页：https://github.com/TakWolf/fusion-pixel-font

`serif-sc.woff2`：Noto Serif SC（思源宋体）粗体的子集，Google / Adobe，SIL Open Font License 1.1。
只收了斜俯视版用到的字（伤害数字、连段字、HUD 标题），由 `tools/fonts/fetch_serif.py` 生成；加了新文字要重新跑。
