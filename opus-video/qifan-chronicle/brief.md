# brief · 起凡编年史（方案 B：像素网吧 → 高清时代）

```text
<role>

</role>

<inputs>
主题：起凡游戏平台二十年编年史（2006—2026）
想让观众记住的一句话：画面跟着时代一起"升级"——从网吧里的 CRT 像素，到电竞舞台，再到今天的高清国风 MOBA；平台还在运行。
原材料：
  - 事实：见本文末尾「事实表」，只用表里的内容
  - 官方素材：source/assets/（来源见 source/assets/SOURCES.md）
规格：92 秒，1080×1920（9:16 竖屏，抖音/快手），30fps
品牌：起凡红 #c4302b，金 #e2b65c；像素段霓虹红 #ff4670、琥珀 #ffcf4a、CRT 绿；
      字体：像素段 Noto Sans SC 900 取阈值硬边；舞台段 Noto Sans SC 900 + Noto Serif SC 900；高清段 Noto Serif SC + Ma Shan Zheng
声音：代码合成配乐 120 BPM（每拍 0.5s）。第一幕 8-bit 芯片音乐（方波琶音 + 噪声鼓）；
      第二幕电子鼓 + 合成器重音；第三幕交响铺底 + 太鼓 + 古筝；结尾芯片动机回归。不配音（默认值）。
</inputs>

<direction>
风格：每个年代换一种画法，画面"随时代升级"。
  第一幕 2006–2008：凌晨网吧，CRT 显示器里的像素画；WebGL CRT 着色器（弧面、扫描线、荧光点、光晕、色散）。
  转场 2008→2011：屏幕"升级"——像素格从 4px → 2px → 1px 逐级变清晰，CRT 弧面拉平。
  第二幕 2011–2014：电竞舞台，LED 大屏、扫光、数据大字，干净锐利（HTML/CSS/SVG）。
  第三幕 2019–2026：高清国风，官方实机截图做成 3D 卡片墙，镜头穿行（CSS 3D）。
  结尾：回到网吧那台唯一亮着的 CRT，像素字收尾，首尾呼应。
每个镜头只讲一件事，字少而大，每段文字至少停留 2.5 秒。
动画用缓动或闭式弹簧（大字 w10 z0.9；卡片 w15 z0.72；指示条 w24 z0.8），不用匀速运动。
转场从画面内容里长出来：开机闪白、屏幕推进、分辨率升级、LED 熄灭，不用默认的淡入淡出。
镜头：持续推拉；第一幕从网吧全景推进到主显示器屏幕；第三幕镜头在卡片墙之间穿行。主体至少占画面三分之一。
安全区：重要文字在 x 80–940、y 260–1500 之内（避开抖音右侧按钮和底部文案区）。
禁止：深色背景 + 居中大字 + 所有元素同时淡入的默认风格；满屏小字；角落多余标签；真人玩家照片；未经核实的数字和年份。
</direction>

<build>
1. 画面：单个 index.html。第一幕 / 转场 / 结尾：Canvas 2D 按逻辑坐标 1080×1920 绘制到低分辨率画布（1080/k，k=4/2/1），再交给 WebGL2 CRT 着色器；
   第二幕、第三幕：HTML/CSS/SVG + CSS 3D。只用 source/assets 中的官方素材，不用其他外部图片。
2. 页面暴露 window.render(t)，画出第 t 秒；所有画面只由 t 算出来，随机数带固定种子，不用计时器，帧和帧之间不保存状态。
3. 渲染：Playwright 逐帧调用 render(t) 截图（本地 http 服务），ffmpeg 合成 MP4。
4. 声音：Python numpy 合成，三幕三种音色，音效时间点直接取自画面代码的关键帧表；混音后响度 -14 LUFS，峰值低于 -1 dBTP。
5. 每做完一个镜头渲 3 张静帧自己检查：文字溢出、元素重叠、主体大小、文字停留时间，修好再做下一个。
</build>

<gotchas>
- 字体加载完再截图；像素字用阈值硬边，逻辑字号 ≥ 18px（在 270 宽画布上）。
- WebGL 先渲一帧确认着色器生效；每帧 gl.finish()。
- 官方截图本身带文案，叠字要避开图里的字，或压暗图片再叠。
- 竖屏安全区：底部 420px 和右侧 140px 不放关键信息。
- 不确定的事实（三国争霸上线时间、在线峰值口径）片尾注明「以官方为准」。
</gotchas>
```
