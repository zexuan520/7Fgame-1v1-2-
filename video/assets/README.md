# 素材目录

把文件按下面的名字放进本目录，重新运行 `node video/render.mjs` 即可自动替换。缺哪个，就用程序生成的画面代替哪个。

| 文件名 | 出现位置 | 建议规格 |
| --- | --- | --- |
| `logo.png` | 片头标题上方、片尾 | 透明背景 PNG，高 ≥ 300px |
| `sgzb-1.jpg` | 2007《三国争霸》 | 16:9 游戏截图，≥ 1600×900 |
| `qxzl-1.jpg` | 2008《群雄逐鹿》 | 16:9 游戏截图，≥ 1600×900 |
| `sgzb2-1.jpg` | 2013《三国争霸2》 | 16:9 游戏截图，≥ 1600×900 |

截图会自动做缓慢推镜（Ken Burns）和扫光效果。
