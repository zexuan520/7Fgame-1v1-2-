# 残刃归途 · 战斗原型

只狼式 2D 横版战斗的第一个可玩原型（设计文档里程碑 1 的第一步）。角色、场景和特效都是用代码画的像素美术（参考死亡细胞、神之亵渎）：角色由骨骼姿势驱动，有明暗、衣摆和轮廓光；场景分层视差，带灯笼光、月光、雾和萤火；画面在 640×360 下渲染再放大，并加了泛光、调色和暗角。

## 怎么运行

1. 安装 [Godot 4.7.2](https://godotengine.org/download)（标准版即可，不需要 .NET 版；4.3 以上的 4.x 也能运行）。
2. 拉取本分支：`git clone -b claude/combat-prototype-00zxtn https://github.com/zexuan520/7Fgame-1v1-2-.git`
3. 打开 Godot → 「导入」→ 选择仓库里的 `project.godot` → 「导入并编辑」。
4. 按 F5（或右上角 ▶）运行。

## 攻击招式

数据在 `scripts/moves.gd`，加一条就是一个新招式。

| 招式 | 怎么出 | 特点 |
| --- | --- | --- |
| 横斩 → 上撩 → 竖劈 → 突刺 → 旋风斩 | 地面连按攻击 | 五段连招，每段方向不同；突刺往前冲，旋风斩原地转一圈前后都砍 |
| 重劈 | 长按攻击 0.6 秒 | 架势伤害 ×2，能破格挡和盾 |
| 升龙斩 | 按住下 + 攻击（连招中途也行） | 连人带刀往上冲，把杂兵挑飞；空中可以接空中斩 |
| 空中斩 → 空中回斩 | 空中按攻击 | 出刀时不往下掉，每次跳起最多两下 |
| 落雷斩 | 空中按住下 + 攻击 | 刀尖朝下砸到地上，落地前后震开一圈，能破格挡 |
| 闪身突刺 | 闪身中或刚闪完按攻击 | 顺着闪身方向冲很远，带残影 |

一套能连起来的打法：地面三四下 → 下+攻击挑飞 → 空中斩两下 → 下+攻击砸下来。

## 对手（数字键切换）

| 键 | 遭遇 |
| --- | --- |
| 1 | 堕落浪人（精英，开局默认） |
| 2 | 野狗群（3 只） |
| 3 | 盾兵 + 两个弓手 |
| 4 | 荒村混战（盾兵、野狗、弓手、浪人一起上） |
| 5 | 第一层头目「断水 · 柳江远」 |

打光一批 3 秒后会重新刷出来。不管场上有几个敌人，同一时间最多两个出招，其余的在外圈转着等机会。

### 杂兵

杂兵没有架势条，头上只有一条小血条，血打空直接倒下，不用处决。弹反杂兵会把它弹开僵直。

| 杂兵 | 打法 |
| --- | --- |
| 野狗 | 跑得快，低吼蓄力后扑咬，咬完就跳开。咬和飞扑都能弹反；跳起踩头会让它僵直。三刀左右砍死。 |
| 弓手 | 站在远处拉弓，弓前白光一闪就放箭。箭能格挡；看准时机弹反，箭会飞回去射中弓手。贴身时它会踢一脚再后跳拉开。 |
| 盾兵 | 举着木盾往前压，正面的轻攻击全部被挡，挡三下会用盾顶回来。重击或回旋斩能破盾；两个人可以一前一后绕背砍。长枪突刺是危招，要看破。 |

### 头目「断水 · 柳江远」

第一层的教学头目，三管血三个阶段。按 5 开场时他背对你站在河边，说完话才转身拔刀，名字出现后开打（走近会让他提前转身）。

| 阶段 | 新招式 |
| --- | --- |
| 一 | 流水三连（弹反）、快斩、虚斩（像流水三连的第一刀，蓄到一半变成突刺，亮危时看破）、擒拿（危，张开手扑过来，格挡没用，要往后闪；被抓住吃双倍伤害）、下段横扫（危，跳） |
| 二 | 出招快 10%，蓝色的气。加入迟斩（举刀过顶停很久才砍，弹早了会挨刀）、后跃接突刺、居合·断水（收刀蓄力后冲刺拔刀横斩，距离很远，可以弹反） |
| 三 | 出招快 20%，流水三连换成流水五连，假动作和居合更多 |

### 精英「堕落浪人」

浪人有两管血、四个招式：

| 招式 | 怎么认 | 怎么应对 | 奖励 |
| --- | --- | --- | --- |
| 三连斩 | 举刀，出刀前刀尖白光一闪 | 白光时按格挡，三下都能弹反 | 每次弹反敌人架势 +15 |
| 快斩 | 同上，前摇更短 | 弹反 | 同上 |
| 下段横扫（危） | 身体红框闪烁、蹲低 | 跳起，落在它头上 | 踩头：敌人架势 +30% 并僵直 |
| 突刺（危） | 红框闪烁、往后撤 | 按着朝它的方向闪身（看破） | 敌人架势 +40% 并僵直 |

把架势条压满（或血打空）后，敌人身上出现红点，2 秒内贴近按攻击就能处决，扣掉一管血。第二管血出招更快、更爱格挡。
连续砍它的格挡三下，它会立刻反击，所以别贪刀。双人时敌人生命 ×1.6、架势 ×1.4。

## 已实现的规则（数值取自设计文档）

- 弹反窗口 0.15 秒（低难度 0.25 秒）；乱按格挡时窗口缩小。弹反时自己架势 +25%，敌人受该招架势值 50% 的反震。
- 普通格挡：不掉血，架势吃满额。挨打：掉血，架势 +50%。
- 架势 1.5 秒不受攻击后开始回落，生命越低回落越慢（回落速度 × 当前生命比例）。
- 玩家架势满：破防僵直 1.2 秒。敌人架势满：处决窗口 2 秒。
- 轻攻击伤害与架势伤害大致 1:1；重攻击架势伤害 ×2，能破敌人格挡。
- 闪身无敌 0.2 秒，冷却 0.4 秒。
- 弹反、看破、处决带顿帧和镜头震动。

- 药罐：喝药 0.95 秒，第 0.6 秒才回血，期间被砍中这一口就浪费了。
- 刃意（生命条下方第三条）：命中 +4、破招 +6、踩头 +8、弹反 +12、看破 +15、处决 +35，上限 100。攒满一格（40）按招式键放回旋斩：原地转两圈前后都砍，每圈 22 伤害、40 架势，能破格挡，转的时候不吃伤害。

### 收刀与拔刀

平时刀收在腰间鞘里，走路两手自然摆动；敌人进入 260 像素内会自动拔刀，打完 2.5 秒附近没敌人就纳刀入鞘。在鞘里直接按攻击也能立刻出刀。

### 架势（起手式）

敌人靠近时主角会摆出当前架势，第一刀从架势出，各有特点（数据在 `scripts/stance.gd`，加一条就是一个新架势）：

| 架势 | 样子 | 效果 |
| --- | --- | --- |
| 正眼 | 中段持刀，刀尖对眼 | 攻守均衡 |
| 拔刀 | 刀在鞘中，手按刀柄 | 第一刀居合横斩：出手快一倍、伤害 ×1.5、距离 +12；砍完一秒后收刀 |
| 上段 | 举刀过顶 | 第一刀重劈：出手慢，伤害 ×1.3、架势伤害 ×1.6 |
| 下段 | 刀尖垂地 | 弹反窗口 +0.04 秒，格挡时架势增长 ×0.75，第一刀上撩 |
| 八相 | 刀立肩旁 | 连击后摇缩短 30% |
| 胁构 | 刀藏身后 | 第一刀撩斩距离 +15，刃意多攒 50% |

还没做的：关卡和肉鸽流程、第二、三层的敌人和头目。

## 加新敌人

敌人的数值、外观、招式和 AI 都在 `scripts/enemy_data.gd` 的 `TYPES` 里，每个招式写前摇/判定/后摇、伤害、判定框、能不能挡、用哪两个姿势；头目的每个阶段可以换招式表和出招速度。遭遇在同一个文件的 `ENCOUNTERS` 里。新姿势加在 `Enemy._build_poses()`；画法完全不同的敌人（比如四条腿的野狗）继承 `Enemy` 重写 `_draw()`，见 `scripts/dog.gd`。

## 自动测试

```
godot --headless --path . res://tests/test_combat.tscn
```

会用模拟按键验证弹反、格挡、看破、跳过横扫、处决、重击、药罐、刃意招式、架势、双人加成，以及杂兵（野狗砍死、弹反僵直、挡箭和弹回箭、盾兵破盾和绕背）、同时出招上限、头目的虚斩、擒拿、三个阶段和登场，全部通过时输出「全部测试通过」。

## 文件结构

- `scenes/main.tscn`：主场景（场地、角色和界面都在 `scripts/main.gd` 里用代码生成）
- `scripts/fighter.gd`：玩家和敌人共用的生命、架势逻辑
- `scripts/player.gd`：主角
- `scripts/enemy_data.gd`：所有敌人和遭遇的数据表
- `scripts/enemy.gd`：敌人的通用状态机、AI、受击和画法；`scripts/dog.gd` 野狗；`scripts/arrow.gd` 箭
- `scripts/puppet.gd`：像素小人（骨骼姿势、插值动画）
- `scripts/background.gd`：夜晚山寺场景（分层视差）
- `shaders/post.gdshader`：画面后期（泛光、调色、暗角、闪光）
- `assets/fonts/`：像素字体 Fusion Pixel（SIL OFL 1.1）
- `scripts/hud.gd`、`scripts/fx.gd`、`scripts/fx_*.gd`：界面和特效（刀光、残影、血、尘土、冲击环）
- `scripts/game.gd`：按键映射、字体和全局开关
