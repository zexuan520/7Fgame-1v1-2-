# 残刃归途 · 战斗原型

只狼式 2D 横版战斗的第一个可玩原型（设计文档里程碑 1 的第一步）。角色、场景和特效都是用代码画的像素美术（参考死亡细胞、神之亵渎）：角色由骨骼姿势驱动，有明暗、衣摆和轮廓光；场景分层视差，带灯笼光、月光、雾和萤火；画面在 640×360 下渲染再放大，并加了泛光、调色和暗角。

## 怎么运行

1. 安装 [Godot 4.7.2](https://godotengine.org/download)（标准版即可，不需要 .NET 版；4.3 以上的 4.x 也能运行）。
2. 拉取本分支：`git clone -b claude/combat-prototype-00zxtn https://github.com/zexuan520/7Fgame-1v1-2-.git`
3. 打开 Godot → 「导入」→ 选择仓库里的 `project.godot` → 「导入并编辑」。
4. 按 F5（或右上角 ▶）运行。

## 操作

| 动作 | 1P 键盘 | 2P 键盘 | 手柄 |
| --- | --- | --- | --- |
| 移动 | A / D | ← / → | 左摇杆或十字键 |
| 跳跃（可二段跳） | W 或 空格 | ↑ | A |
| 攻击（短按轻击三连，长按 0.6 秒重击） | J | 小键盘 1 或 `,` | X |
| 格挡（按准时机即弹反） | K | 小键盘 2 或 `.` | RB |
| 闪身（不按方向是后撤） | L 或 Shift | 小键盘 3 或 `/` | B |
| 处决 | 敌人出现红点时按攻击 | 同左 | 同左 |
| 药罐（回 40% 生命，共 3 次） | U | 小键盘 4 或 M | Y |
| 刃意招式·回旋斩（耗 40 刃意） | I | 小键盘 5 或 N | LB |

其他按键：F2 让 2P 加入或退出（2P 按攻击键也能直接加入）· F1 切换低难度弹反窗口 · F3 显示判定框 · R 重置 · H 打开操作说明 · Esc 退出。
第 1 个手柄归 1P，第 2 个手柄归 2P。

## 怎么打练手敌人「浪人」

浪人有两管血、四个招式：

| 招式 | 怎么认 | 怎么应对 | 奖励 |
| --- | --- | --- | --- |
| 三连斩 | 举刀，出刀前刀尖白光一闪 | 白光时按格挡，三下都能弹反 | 每次弹反敌人架势 +15 |
| 快斩 | 同上，前摇更短 | 弹反 | 同上 |
| 下段横扫（危） | 身体红框闪烁、蹲低 | 跳起，落在它头上 | 踩头：敌人架势 +30% 并僵直 |
| 突刺（危） | 红框闪烁、往后撤 | 按着朝它的方向闪身（看破） | 敌人架势 +40% 并僵直 |

把架势条压满（或血打空）后，敌人身上出现红点，2 秒内贴近按攻击就能处决，扣掉一管血。第二管血出招更快、更爱格挡。
连续砍它的格挡三下，它会立刻反击，所以别贪刀。双人时敌人生命 ×1.6、架势 ×1.4。

## 已实现的规则（数值取自设计文档）

- 弹反窗口 0.15 秒（低难度 0.25 秒）；乱按格挡时窗口缩小。弹反时自己架势 +25%，敌人受该招架势值 50% 的反震。
- 普通格挡：不掉血，架势吃满额。挨打：掉血，架势 +50%。
- 架势 1.5 秒不受攻击后开始回落，生命越低回落越慢（回落速度 × 当前生命比例）。
- 玩家架势满：破防僵直 1.2 秒。敌人架势满：处决窗口 2 秒。
- 轻攻击三段连击，伤害与架势伤害 1:1；重攻击架势伤害 ×2，能破敌人格挡。
- 闪身无敌 0.2 秒，冷却 0.4 秒。
- 弹反、看破、处决带顿帧和镜头震动。

- 药罐：喝药 0.95 秒，第 0.6 秒才回血，期间被砍中这一口就浪费了。
- 刃意（生命条下方第三条）：命中 +4、破招 +6、踩头 +8、弹反 +12、看破 +15、处决 +35，上限 100。攒满一格（40）按招式键放回旋斩：原地转两圈前后都砍，每圈 22 伤害、40 架势，能破格挡，转的时候不吃伤害。

还没做的：更多敌人和 BOSS、关卡。

## 自动测试

```
godot --headless --path . res://tests/test_combat.tscn
```

会用模拟按键验证弹反、格挡、看破、跳过横扫、处决、重击、药罐、刃意招式和双人加成，全部通过时输出「全部测试通过」。

## 文件结构

- `scenes/main.tscn`：主场景（场地、角色和界面都在 `scripts/main.gd` 里用代码生成）
- `scripts/fighter.gd`：玩家和敌人共用的生命、架势逻辑
- `scripts/player.gd`：主角
- `scripts/enemy.gd`：练手敌人「浪人」
- `scripts/puppet.gd`：像素小人（骨骼姿势、插值动画）
- `scripts/background.gd`：夜晚山寺场景（分层视差）
- `shaders/post.gdshader`：画面后期（泛光、调色、暗角、闪光）
- `assets/fonts/`：像素字体 Fusion Pixel（SIL OFL 1.1）
- `scripts/hud.gd`、`scripts/fx.gd`、`scripts/fx_*.gd`：界面和特效（刀光、残影、血、尘土、冲击环）
- `scripts/game.gd`：按键映射、字体和全局开关
